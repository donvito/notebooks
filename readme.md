# Colab Notebooks

Free Google Colab notebooks for trying new open models. Click **Open in Colab** to run one; **Use cases** explains when to pick it.

**Runs on** is the Colab runtime you need. *CPU or GPU* works on the free CPU runtime (a GPU is faster). *T4 GPU* needs *Runtime > Change runtime type > T4 GPU*. The size is the model download.

Tweet + Hub sources: see [tweet-sources.md](tweet-sources.md).
